# Agentic Directives: copilot-cli/references

**Goal**: Maintain strict, high-density, system-log style documentation artifacts within the `references/` directory.

## Source Invariant

- The baseline for all reference files is: [github/docs/.../copilot-cli](https://github.com/github/docs/tree/main/content/copilot/how-tos/copilot-cli).
- ALL reference files MUST be generated by extracting raw Markdown from this authoritative GitHub Docs repository.
- NEVER hallucinate schemas or tool commands; extrapolate purely from the upstream source.

## Generation Protocol

1. **Fetch**: Target the authoritative raw `.md` source.
2. **Prune**: Annihilate all conversational prose, pleasantries, and introductory filler.
3. **Structure**: Force the extracted data into the standardized Agentic Schema (below).
4. **Link**: Append the canonical GitHub Docs URL natively under `## References`.

## Required Output Schema

```markdown
# [Topic Title]

**Goal**: [One-sentence declarative objective]

## Invariants

- [Strict constraints, limitations, and operational rules]

## Schema (if applicable)

- [JSON/YAML layouts, file paths, frontmatter fields, valid values]

## Commands / Execution (if applicable)

- [Exact CLI commands, environmental setups, and operational flags]

## References

- [Canonical GitHub Docs URL]
```
