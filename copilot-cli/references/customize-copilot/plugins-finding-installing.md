# Finding & Installing Plugins

**Goal**: Extend environment with community marketplace plugins.

### Invariants
- Plugin names resolve via marketplace registry.
- Environment variables control offline installation.

### Commands
Execute:
- `/plugin marketplace add <URL>`
- `/plugin install <PLUGIN-NAME>@<MARKETPLACE-NAME>`
- `/plugin list`
- `/plugin marketplace remove <MARKETPLACE-NAME>`
