# Plugins Marketplace

**Goal**: Access or self-host custom CLI extensions.

### Schema
```json
{
  "plugins": [
    {
      "name": "terraform-helper",
      "version": "1.0.0",
      "url": "https://server/plugin.tar.gz"
    }
  ]
}
```

### Commands
Execute: Define standard registry via config injection.
